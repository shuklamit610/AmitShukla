# QR Code Generator
## Description

This project is a Python-based QR Code Generator. The application
accepts a URL from the user and converts the URL into a
machine-readable QR code.

The generated QR code is saved as a PNG image and displayed using
OpenCV.

## Technologies Used

- Python
- QRCode Python Library
- OpenCV
- Visual Studio Code
- GitHub

## Installation

Clone the repository and navigate to the project directory.

Install the required Python packages:

    pip install -r requirements.txt

## Running the Application

Run the following command:

    python qr_code_generator.py

Enter a URL when prompted.

For example:

    https://www.bioxsystems.com/

The application generates a QR code and displays it in an image
window.

## Output

The application creates a file named:

    qr_code.png

The generated QR code can be scanned using a smartphone or QR
code reader.
